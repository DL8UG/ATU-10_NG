ATU-10 NG Cell Editor

Change the settings in a firmware hex file. Runs offline in your browser, nothing is uploaded.

Drop the firmware .hex file here or click to choose it

#SettingValueMeansHex
Copy the saved file onto the tuner's USB drive as usual.

The settings ("Cells") are 12 BCD coded bytes at address 0xEEE0 of the hex file (records :10EEE000 and :10EEF000). The editor changes only these bytes and the record checksums. Values set later in the tuner's setup menu take precedence until the hex file's Cells change.
